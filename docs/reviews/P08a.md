Disposition: no blocking findings. The trusted caller selects the role and expected key ID, not the submitted artifact. Whole-artifact and encoded/decoded segment limits apply before relevant allocations. Exactly three nonempty canonical base64url segments are required. Headers pass strict duplicate/type checks and must match the accepted deterministic bytes exactly. A distinct issuer key ID is not incorrectly equated with the payload issuer identity; registry binding remains future work.
