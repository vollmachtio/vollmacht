# P07c canonical envelope and digest review

Implementation author: `contract_revision`. Independent test author: `p06_acceptance_audit`. Independent adversarial reviewer: `adversarial_p02`. Reviewed delta starts after P07b commit `9d401d8`.

Disposition: no blocking findings. Full original-envelope canonical equality is proved before nested approval reserialization is used for its raw byte cap. Noncanonical padding or escaping cannot disappear before that comparison. Envelope and evidence field sets are exact; byte fields require bounded canonical base64url and credential IDs agree with the nested approval. Evidence bytes remain opaque and unverified.

Digest functions accept immutable schema-valid inputs and use the maintained fallible OpenSSL SHA-256 API. The mandate, operation and envelope domains contain exactly one terminal NUL. No primitive, alternate hash profile or input-supplied algorithm was introduced. The operation digest excludes authority/display/evidence by design; mandate and envelope bindings include their respective complete canonical objects. Matching digests do not grant authority.

Independent tests use the accepted current-profile fixture's literal canonical envelope and three digest values. They cover field/type rejection, evidence byte boundaries and noncanonical encodings, credential mismatch, original signed-byte preservation, nested approval failures, outer and nested noncanonical whitespace, original size limits, digest mutation sensitivity and operation-digest invariance under authority-only changes. Synthetic evidence is not claimed valid WebAuthn evidence merely because its schema passes.
