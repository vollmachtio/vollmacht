## Validation

Both author and reviewer independently ran `python3 scripts/check.py`: formatting, warnings-as-errors Clippy, release build, 28 Rust tests and 4 JavaScript tests passed. The JavaScript tests execute the shipped script with stubs; they are not real browser tests.

Author additionally ran `python3 scripts/dependencies.py` with refreshed advisory data on 2026-09-20: advisories, licenses, bans and sources passed. Existing duplicate-version warnings remain visible. The reviewer inspected the version-scoped BSD license exceptions but did not independently rerun the advisory audit.

Author ran the release binary against a real loopback socket: landing response and authenticated registration-options request passed. The process was stopped immediately, its ephemeral token was not printed in validation output, and no physical authenticator was invoked. This confirms transport startup, not passkey interoperability.

Tests caught acceptance of unknown fields on Serde unit command variants. Converting start commands to empty struct variants now enforces rejection; an HTTP regression test covers this. Additional tests cover failed registration, exact TTL boundaries, stale IDs, wrong ceremony kind, atomic concurrent completion, missing/duplicate HTTP security headers, request size, binary browser encoding, validly signed wrong RP ID, and missing UP in valid none-attestation registration with a success control.
