# P08b signature verification review

Implementation author: `contract_revision`. Independent integration-test author: `p06_acceptance_audit`. Independent adversarial reviewer: `adversarial_p02`. Reviewed delta follows P08a compact preflight.

Disposition: no blocking findings. Explicit startup installs the custom provider once, rejecting foreign or previously installed providers. A failed startup self-check yields no runtime capability and cannot be retried. Initialization before listeners/workers is an explicit caller duty, not a claimed OS-thread inspection. Unsupported signing and key-utility callbacks return errors rather than using the library's panic stubs.

Private verification bindings validate the caller's expected role and key ID. Agent roles recompute the validated public-key thumbprint. Issuer labels remain independent registry labels. Strict compact preflight precedes signature-verifying `jsonwebtoken::decode`; generic JWT time/audience checks are explicitly disabled without disabling signature verification. OpenSSL checks P-256, scalar bounds and SHA-256 over the original signing input. No key material comes from submitted headers.

The startup public known-answer vector matches [RFC 6979 Appendix A.2.5](https://www.rfc-editor.org/rfc/rfc6979.html#appendix-A.2.5), P-256/SHA-256 for `sample`, with a modified-message negative control. The coordinator checked public coordinates and signature scalars against the primary RFC text. No private key or runtime fixture read is needed.

## Validation and dependency delta

- Independent reviewer: 60 core tests, strict Clippy, formatting and 128-source inventory passed.
- Coordinator: complete pinned-runtime `python3 scripts/check.py` and `python3 scripts/dependencies.py` passed.

Signature success is not trusted registry resolution, freshness, revocation, replay protection, WebAuthn verification or permission to enroll/dispatch. Encoder guards and signer-handle binding remain future P08 work. Exact integrated-head mandatory CI is required before protected merge.
